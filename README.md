### Description of the Task

The task is to **design and implement a Basic Arithmetic Logic Unit (ALU)** using **Verilog/VHDL Hardware Description Language**. The ALU is an important digital circuit used in processors and computer systems to perform arithmetic and logical operations.

The designed ALU should support the following operations:

* Addition
* Subtraction
* AND
* OR
* NOT

The operation performed by the ALU is selected using control or selection lines.

---

# Objectives

* To understand the working of an ALU.
* To design arithmetic and logical circuits using HDL.
* To write Verilog/VHDL code for ALU operations.
* To create a testbench for verification.
* To simulate and verify the output results.
